# Пакет для встречи с руководством

**Назначение:** всё необходимое, чтобы за одну встречу (30–60 мин) объяснить проект, показать демо, получить решения и согласовать следующие шаги.  
**Репозиторий:** https://github.com/Borisserz/prototip  
**Дата:** июнь 2026

---

# Часть 1. За 2 минуты — что сказать в начале

> **prototip** — локальная система, где руководитель задаёт вопрос на русском и за минуту получает график, цифры и выводы. При необходимости — дашборд или презентацию PowerPoint. Работает офлайн на компьютере, без отправки данных в облако.
>
> **Сейчас:** готовый демонстрационный прототип на синтетических налоговых данных (7 регионов РБ, 5 видов налогов). 146 автотестов, мультиагентная архитектура по образцу современных BI+AI решений.
>
> **Это не** готовый продукт для всей организации. **Это** доказательство концепции и фундамент для пилота — при получении реальных данных, метрик и требований к интерфейсу от заказчика.

# Часть 3. Честные ограничения (сказать до вопросов)

| Ограничение | Пояснение для руководства |
|-------------|---------------------------|
| Синтетические данные | Цифры для демонстрации логики, не для официальных решений |
| Одна таблица | Нет подключения к промышленной БД организации |
| Локальная модель 7B | На сложных вопросах возможны ошибки в SQL |
| Время ответа | 30 сек – несколько минут (презентация дольше) |
| Нет входа по паролю | Прототип без учётных записей |
| Интерфейс Streamlit | «Продуктовый» вид — после брендбука заказчика |
| RAG не используется | Знания о данных — через согласованный каталог метрик (YAML) |

# Часть 9. FAQ — ответы на типичные вопросы руководства

**Это заменяет аналитиков?**  
Нет. Закрывает рутинные ad-hoc запросы. Аналитик остаётся для сложной логики, валидации метрик и сопровождения каталога.

**Данные уходят в интернет?**  
В текущем прототипе — нет, всё локально (Ollama). Для продукта — решение за руководством (on-prem vs API).

**Насколько это похоже на Epsilon / другие вендоры?**  
По идее «вопрос → агенты → график» — близко. По корпоративным данным и эксплуатации — мы на старте. Таблицы: [SRAVNENIE_S_EPSILON_METRICS.md](SRAVNENIE_S_EPSILON_METRICS.md).

**Сколько стоит поддержка?**  
Прототип — внутренняя разработка. Продукт: оценка после фазы 0 (зависит от числа таблиц, UC, требований к UI и инфраструктуре).

**Можно ли начать без реальной БД?**  
Да — демо уже работает. Продуктовый пилот без sandbox **не имеет смысла** (нечего показывать руководству заказчика).

**Что если ИИ ошибся?**  
В режиме аналитика виден SQL. В продукте — политика: скрыть ответ / показать с дисклеймером / эскалация аналитику (согласовать в acceptance_criteria).
