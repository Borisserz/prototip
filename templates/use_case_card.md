## Пример (demo prototip)

| Поле | Значение |
|------|----------|
| **ID** | UC-01 |
| **Название** | Обзор задолженности по регионам |
| **Персона** | Руководитель финансов |
| **Приоритет** | MVP |
| **Частота** | Еженедельно |

**Вопрос:** «Какие регионы имеют наибольшую задолженность по НДС?»

**Ожидаемый результат:** горизонтальная диаграмма топ регионов + 3–4 тезиса + ключевой вывод.

**SQL:**

```sql
SELECT region, SUM(debt) AS total_debt
FROM df
WHERE tax_type = 'НДС'
GROUP BY region
ORDER BY total_debt DESC
LIMIT 10
```

**SLA:** < 90 сек  
**Действия после:** обсуждение на совещании, опционально — слайд в pptx
