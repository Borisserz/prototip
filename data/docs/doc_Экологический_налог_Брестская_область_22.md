# Статья 961. Порядок исчисления и уплаты налога: Экологический налог.
    
Для региона **Брестская область** устанавливаются следующие правила.
Налоговой базой признается стоимость реализованных товаров (работ, услуг), имущественных прав.
Базовая ставка налога составляет 6%.

В случае возникновения просроченной задолженности свыше 84 дней, применяется штрафная пеня в размере 0.05% за каждый день просрочки.
