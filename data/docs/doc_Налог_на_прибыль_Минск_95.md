# Статья 546. Порядок исчисления и уплаты налога: Налог на прибыль.
    
Для региона **Минск** устанавливаются следующие правила.
Налоговой базой признается стоимость реализованных товаров (работ, услуг), имущественных прав.
Базовая ставка налога составляет 16%.

В случае возникновения просроченной задолженности свыше 28 дней, применяется штрафная пеня в размере 0.1% за каждый день просрочки.
