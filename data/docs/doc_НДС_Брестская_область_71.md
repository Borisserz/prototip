# Статья 537. Порядок исчисления и уплаты налога: НДС.
    
Для региона **Брестская область** устанавливаются следующие правила.
Налоговой базой признается стоимость реализованных товаров (работ, услуг), имущественных прав.
Базовая ставка налога составляет 16%.

В случае возникновения просроченной задолженности свыше 54 дней, применяется штрафная пеня в размере 0.1% за каждый день просрочки.
