# Статья 849. Порядок исчисления и уплаты налога: Подоходный налог.
    
Для региона **Брестская область** устанавливаются следующие правила.
Налоговой базой признается стоимость реализованных товаров (работ, услуг), имущественных прав.
Базовая ставка налога составляет 19%.

В случае возникновения просроченной задолженности свыше 79 дней, применяется штрафная пеня в размере 0.1% за каждый день просрочки.
