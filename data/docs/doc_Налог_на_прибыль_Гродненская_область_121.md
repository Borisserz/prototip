# Внутренний регламент инспекции Гродненская область. Взыскание по налогу: Налог на прибыль.
    
При выявлении задолженности по Налог на прибыль свыше 10 000 Br, инспектор обязан направить уведомление в течение 38 дней.
Процент взыскания составляет 17%, пеня 0.01%.
Если налогоплательщик уклоняется, дело передается в суд. Уникальный код регламента: 982e7623.
