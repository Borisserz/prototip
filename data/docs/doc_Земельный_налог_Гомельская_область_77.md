# Внутренний регламент инспекции Гомельская область. Взыскание по налогу: Земельный налог.
    
При выявлении задолженности по Земельный налог свыше 10 000 Br, инспектор обязан направить уведомление в течение 89 дней.
Процент взыскания составляет 8%, пеня 0.05%.
Если налогоплательщик уклоняется, дело передается в суд. Уникальный код регламента: 48a9e733.
