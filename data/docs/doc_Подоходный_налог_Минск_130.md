# Статья 156. Порядок исчисления и уплаты налога: Подоходный налог.
    
Для региона **Минск** устанавливаются следующие правила.
Налоговой базой признается стоимость реализованных товаров (работ, услуг), имущественных прав.
Базовая ставка налога составляет 29%.

В случае возникновения просроченной задолженности свыше 22 дней, применяется штрафная пеня в размере 0.01% за каждый день просрочки.
