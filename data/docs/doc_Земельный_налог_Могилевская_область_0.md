# Статья 567. Порядок исчисления и уплаты налога: Земельный налог.
    
Для региона **Могилевская область** устанавливаются следующие правила.
Налоговой базой признается стоимость реализованных товаров (работ, услуг), имущественных прав.
Базовая ставка налога составляет 10%.

В случае возникновения просроченной задолженности свыше 19 дней, применяется штрафная пеня в размере 0.05% за каждый день просрочки.
