# Статья 652. Порядок исчисления и уплаты налога: Земельный налог.
    
Для региона **Минск** устанавливаются следующие правила.
Налоговой базой признается стоимость реализованных товаров (работ, услуг), имущественных прав.
Базовая ставка налога составляет 10%.

В случае возникновения просроченной задолженности свыше 53 дней, применяется штрафная пеня в размере 0.1% за каждый день просрочки.
