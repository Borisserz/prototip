# Статья 631. Порядок исчисления и уплаты налога: Подоходный налог.
    
Для региона **Минская область** устанавливаются следующие правила.
Налоговой базой признается стоимость реализованных товаров (работ, услуг), имущественных прав.
Базовая ставка налога составляет 30%.

В случае возникновения просроченной задолженности свыше 69 дней, применяется штрафная пеня в размере 0.01% за каждый день просрочки.
