# Внутренний регламент инспекции Гродненская область. Взыскание по налогу: Подоходный налог.
    
При выявлении задолженности по Подоходный налог свыше 10 000 Br, инспектор обязан направить уведомление в течение 26 дней.
Процент взыскания составляет 7%, пеня 0.15%.
Если налогоплательщик уклоняется, дело передается в суд. Уникальный код регламента: 621e1088.
