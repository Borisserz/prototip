# Статья 702. Порядок исчисления и уплаты налога: Налог на прибыль.
    
Для региона **Гомельская область** устанавливаются следующие правила.
Налоговой базой признается стоимость реализованных товаров (работ, услуг), имущественных прав.
Базовая ставка налога составляет 9%.

В случае возникновения просроченной задолженности свыше 25 дней, применяется штрафная пеня в размере 0.1% за каждый день просрочки.
