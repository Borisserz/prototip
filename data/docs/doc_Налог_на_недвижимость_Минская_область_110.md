# Статья 613. Порядок исчисления и уплаты налога: Налог на недвижимость.
    
Для региона **Минская область** устанавливаются следующие правила.
Налоговой базой признается стоимость реализованных товаров (работ, услуг), имущественных прав.
Базовая ставка налога составляет 6%.

В случае возникновения просроченной задолженности свыше 72 дней, применяется штрафная пеня в размере 0.05% за каждый день просрочки.
