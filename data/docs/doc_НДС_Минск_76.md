# Статья 372. Порядок исчисления и уплаты налога: НДС.
    
Для региона **Минск** устанавливаются следующие правила.
Налоговой базой признается стоимость реализованных товаров (работ, услуг), имущественных прав.
Базовая ставка налога составляет 8%.

В случае возникновения просроченной задолженности свыше 64 дней, применяется штрафная пеня в размере 0.1% за каждый день просрочки.
