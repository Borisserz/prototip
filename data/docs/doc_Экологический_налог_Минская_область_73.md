# Статья 942. Порядок исчисления и уплаты налога: Экологический налог.
    
Для региона **Минская область** устанавливаются следующие правила.
Налоговой базой признается стоимость реализованных товаров (работ, услуг), имущественных прав.
Базовая ставка налога составляет 21%.

В случае возникновения просроченной задолженности свыше 82 дней, применяется штрафная пеня в размере 0.01% за каждый день просрочки.
