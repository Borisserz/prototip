# ПРИКАЗ № 404
**От 15.09.2023**
**По Минской области**

О мерах по ужесточению контроля за сборами в секторе Ритейл и IT.

В связи с наблюдаемыми аномалиями (резкое падение сборов в IT отрасли в 2022 году) приказываю:

1. Усилить контроль за налогоплательщиками с отраслью (industry = 'IT') в Минской области и г. Минск.
2. Всех инспекторов обязать использовать дашборды "Prototip BI" для выявления аномальных компаний.
3. Компании, показывающие падение платежей более чем на 50% относительно аналогичного периода прошлого года, немедленно переводить в группу риска с искусственным повышением `risk_score` на +20 баллов.
4. Контроль за исполнением возложить на заместителя начальника инспекции.
