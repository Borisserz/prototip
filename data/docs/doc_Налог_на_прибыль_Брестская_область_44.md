# Статья 717. Порядок исчисления и уплаты налога: Налог на прибыль.
    
Для региона **Брестская область** устанавливаются следующие правила.
Налоговой базой признается стоимость реализованных товаров (работ, услуг), имущественных прав.
Базовая ставка налога составляет 21%.

В случае возникновения просроченной задолженности свыше 37 дней, применяется штрафная пеня в размере 0.05% за каждый день просрочки.
