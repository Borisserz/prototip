# Статья 212. Порядок исчисления и уплаты налога: Налог на прибыль.
    
Для региона **Минская область** устанавливаются следующие правила.
Налоговой базой признается стоимость реализованных товаров (работ, услуг), имущественных прав.
Базовая ставка налога составляет 22%.

В случае возникновения просроченной задолженности свыше 21 дней, применяется штрафная пеня в размере 0.15% за каждый день просрочки.
