# Статья 174. Порядок исчисления и уплаты налога: НДС.
    
Для региона **Минская область** устанавливаются следующие правила.
Налоговой базой признается стоимость реализованных товаров (работ, услуг), имущественных прав.
Базовая ставка налога составляет 27%.

В случае возникновения просроченной задолженности свыше 66 дней, применяется штрафная пеня в размере 0.05% за каждый день просрочки.
