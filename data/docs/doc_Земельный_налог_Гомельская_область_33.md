# Статья 624. Порядок исчисления и уплаты налога: Земельный налог.
    
Для региона **Гомельская область** устанавливаются следующие правила.
Налоговой базой признается стоимость реализованных товаров (работ, услуг), имущественных прав.
Базовая ставка налога составляет 25%.

В случае возникновения просроченной задолженности свыше 87 дней, применяется штрафная пеня в размере 0.15% за каждый день просрочки.
