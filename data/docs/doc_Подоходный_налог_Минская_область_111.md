# Внутренний регламент инспекции Минская область. Взыскание по налогу: Подоходный налог.
    
При выявлении задолженности по Подоходный налог свыше 10 000 Br, инспектор обязан направить уведомление в течение 89 дней.
Процент взыскания составляет 22%, пеня 0.01%.
Если налогоплательщик уклоняется, дело передается в суд. Уникальный код регламента: 587a0216.
