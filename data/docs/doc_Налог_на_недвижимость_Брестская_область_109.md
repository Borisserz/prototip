# Статья 354. Порядок исчисления и уплаты налога: Налог на недвижимость.
    
Для региона **Брестская область** устанавливаются следующие правила.
Налоговой базой признается стоимость реализованных товаров (работ, услуг), имущественных прав.
Базовая ставка налога составляет 12%.

В случае возникновения просроченной задолженности свыше 71 дней, применяется штрафная пеня в размере 0.15% за каждый день просрочки.
