# Статья 682. Порядок исчисления и уплаты налога: Подоходный налог.
    
Для региона **Минская область** устанавливаются следующие правила.
Налоговой базой признается стоимость реализованных товаров (работ, услуг), имущественных прав.
Базовая ставка налога составляет 19%.

В случае возникновения просроченной задолженности свыше 73 дней, применяется штрафная пеня в размере 0.01% за каждый день просрочки.
