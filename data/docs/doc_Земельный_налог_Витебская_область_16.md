# Внутренний регламент инспекции Витебская область. Взыскание по налогу: Земельный налог.
    
При выявлении задолженности по Земельный налог свыше 10 000 Br, инспектор обязан направить уведомление в течение 54 дней.
Процент взыскания составляет 13%, пеня 0.1%.
Если налогоплательщик уклоняется, дело передается в суд. Уникальный код регламента: 81ce4010.
