# Статья 654. Порядок исчисления и уплаты налога: Подоходный налог.
    
Для региона **Минск** устанавливаются следующие правила.
Налоговой базой признается стоимость реализованных товаров (работ, услуг), имущественных прав.
Базовая ставка налога составляет 15%.

В случае возникновения просроченной задолженности свыше 45 дней, применяется штрафная пеня в размере 0.1% за каждый день просрочки.
