# Внутренний регламент инспекции Брестская область. Взыскание по налогу: Подоходный налог.
    
При выявлении задолженности по Подоходный налог свыше 10 000 Br, инспектор обязан направить уведомление в течение 50 дней.
Процент взыскания составляет 6%, пеня 0.01%.
Если налогоплательщик уклоняется, дело передается в суд. Уникальный код регламента: ae7a3b0d.
