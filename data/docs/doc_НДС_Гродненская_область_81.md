# Внутренний регламент инспекции Гродненская область. Взыскание по налогу: НДС.
    
При выявлении задолженности по НДС свыше 10 000 Br, инспектор обязан направить уведомление в течение 56 дней.
Процент взыскания составляет 20%, пеня 0.01%.
Если налогоплательщик уклоняется, дело передается в суд. Уникальный код регламента: cb603879.
