# Внутренний регламент проведения внеплановых проверок (Автоматизированный Аудит)
**Утверждено:** 10.01.2023

## 1. Общие положения
Данный регламент описывает автоматизированную систему назначения аудитов (`has_audit` флаг) для юридических лиц и ИП на основании показателя `risk_score`. 

## 2. Триггеры риска
Система автоматически рассчитывает `risk_score` (от 1 до 100) для каждой транзакции и компании. Если `risk_score > 80`, система:
1. Автоматически переводит транзакцию в очередь на внеплановую проверку.
2. Проверка происходит без уведомления налогоплательщика.
3. По итогам проверки может быть выписан штраф (`fine_amount`), который может составлять от 5000 до 20000 базовых единиц.

## 3. Блокировка счетов
Если компания имеет статус `status = 'Взыскание'` и не оплаченный `fine_amount`, ее счета подлежат немедленной автоматической блокировке через интеграцию с АИС "Банки".
Для разблокировки требуется погасить задолженность в полном объеме и подать заявление через личный кабинет.
