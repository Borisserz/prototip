
```bash
cd prototip

# Инициализация основного стека (если ещё не запущен)
docker compose up -d

# Развертывание демо-базы PostgreSQL (имитирует БД клиента)
docker compose -f demo/docker-compose.demo.yml up -d
```

Подождать ~30 секунд пока поднимется. Проверить:

```bash
docker ps | grep demo
# Должно быть два контейнера: prototip_demo_postgres и prototip_demo_pgadmin
```

## 2. Что запущено

| Сервис | URL | Учётные данные |
|--------|-----|----------------|
| **Prototip BI** (основное приложение) | http://localhost:3000 | admin / (любой пароль) |
| **pgAdmin** (показать «БД клиента») | http://localhost:5050 | admin@prototip.com / admin |
| **Демо PostgreSQL** (порт) | localhost:5435 | demo_user / demo_pass / demo_mns |
| **Swagger API** (при необходимости) | http://localhost:8000/docs | — |

## 3. Сценарий демонстрации (шаг за шагом)

### Демонстрация «базы данных клиента»

1. Открыть **http://localhost:5050** (pgAdmin)
2. Войти: `admin@prototip.com` / `admin`
3. Добавить сервер (один раз):
   - **Имя:** МНС Гродно
   - **Host:** `host.docker.internal`
   - **Port:** `5435`
   - **Database:** `demo_mns`
   - **Username:** `demo_user`
   - **Password:** `demo_pass`
4. Показать таблицы: `tax_data` и `taxpayers_registry`
--

### Создание нового блока в Prototip

1. Открыть **http://localhost:3000**
2. Войти как `admin`
3. Нажать на иконку ⚙️ (Панель администратора) в правом верхнем углу
4. В левом меню выбрать **«Клиенты (B2B)»**
5. Нажать **«Создать клиента»**

В мастере заполнить:
- **ID клиента:** `grodno_mns`
- **Название:** `МНС Гродненской области`
- **DSN подключения к Postgres:**
  ```
  postgresql://demo_user:demo_pass@host.docker.internal:5435/demo_mns
  ```

6. Нажать **«Проверить подключение»** — появится список таблиц
7. Выбрать таблицу `tax_data` (или все)
8. Нажать **«Инициализировать»**

### Работа с данными через чат-интерфейс

После завершения ETL — войти в чат от лица клиента (кнопка **«Войти как клиент»** в карточке).

## 5. Данные в демо-базе

**Таблица `tax_data`** — начисления/платежи/задолженности:
- Период: январь 2024 — март 2025
- 6 районов: г. Гродно, Гродненский, Лидский, Слонимский, Волковысский, Новогрудский
- Виды налогов: НДС, Налог на прибыль, Подоходный налог, Акцизы, Имущественные налоги
- **Встроенная аномалия:** в июле 2024 задолженность выросла вдвое — система её обнаружит сама

**Таблица `taxpayers_registry`** — реестр 17 плательщиков (ОАО, ООО, ИП, КСУП, РУП)

## 6. Остановить демо после встречи

```bash
# Остановить демо-базу (данные сохранятся)
docker compose -f demo/docker-compose.demo.yml stop

# Удалить полностью (если больше не нужно)
docker compose -f demo/docker-compose.demo.yml down -v
```
